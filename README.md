# PRODIGY_DS_01

## Task 1: Data Visualization

This project is part of my Data Science Internship at Prodigy InfoTech.

### Objective
Create a bar chart or histogram to visualize the distribution of a variable using the World Bank Population dataset.

### Dataset
The dataset contains population data for countries and regions from 1960 to 2025.

### Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

### Task Work
- Loaded and explored the World Bank population dataset.
- Analyzed population data for different countries and regions.
- Created a histogram to visualize the population distribution.
- Created a bar chart showing the top 10 most populated countries/regions in 2025.

### File
- `task1.ipynb` — Complete Jupyter Notebook containing the code, analysis, and visualizations.
